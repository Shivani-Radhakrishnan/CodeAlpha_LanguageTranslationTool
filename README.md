
# 🌍 Language Translation Tool

A simple yet effective tool to translate text between multiple languages using the Google Translate API.

## 🚀 Features
- Translate text between 100+ languages
- Clean Streamlit UI
- Optional text-to-speech

## 📦 Tech Stack
- Python
- Streamlit
- Googletrans
- Pyttsx3 (TTS)

## 🧪 How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
