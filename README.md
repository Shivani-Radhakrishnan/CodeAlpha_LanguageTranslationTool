
# 🌍 Language Translation Tool

A simple tool to translate text between 100+ languages, built with Streamlit. Translation uses the
unofficial [`googletrans`](https://pypi.org/project/googletrans/) library, which calls Google Translate's
web service (not the paid Google Cloud Translation API).

## 🚀 Features
- Translate text between 100+ languages
- Clean Streamlit UI
- Optional text-to-speech

## 📦 Tech Stack
- Python
- Streamlit
- Googletrans
- Pyttsx3 (TTS)

## 🧪 How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
